Game Collection

## 4. Project description:
Our project will list games by genre and platform, show gameplay when hovering over the game, and list the games out in a side-by-side swipe format but can be expanded into a list format. It will also have a friends list feature as well as a review system so others can know exactly what the game is about before purchasing it. 

## 5. Tabs List:
For the list tab, we will have a list of games by genre or platform as well as a list of consoles for each game, for the detail tab we will have details of games, gameplay, will show what games we have completed ourselves and a way to recommend games to our friends.

## 6. Technology:
The app and website will take information from Supabase to create more or less identical pages and overall setup for both
